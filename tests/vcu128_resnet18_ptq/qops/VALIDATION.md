# 交付前验证

本记录为交付方离线验证，不是 VCU128 板上结果。

- 使用此前官方 ResNet18 量化导出和 sample_0000 的真实整数输入/中间参考。
- 用例生成：40 项，blob 3,273,632 字节，最大输出 802,816 字节。
- 真实卷积、投影、残差、全局平均和 FC 均在生成时重新计算，并与已保存整数 golden 逐元素核对。
- 原生 GCC 独立标量 INT64 + 当前 C 缩放宏检查全部 40 项通过；包括融合池化、无 ReLU 的有符号卷积、带偏置的 INT32 全宽读出。
- 使用 RISC-V GCC 13.2.0、RV64 IMAFDC + Zicsr/Zifencei、lp64d 完成交叉编译。
- Gemmini API 使用此前已验证快照；参数头采用用户提供的 DIM=8、SP64KiB/ACC32KiB、INT8/INT32 配置。
- hart0 和 hart1 两份 ELF 均通过 PT_LOAD、入口/栈/BSS、构建 ABI、fixture 完整字节和清单摘要检查。
- 两份 image_end 均为 `0x803e6ec0`（其他工具链构建可变化，以本次符号和检查结果为准）。
- 两份 ELF 的 `.text` 均检测到 36 条 custom3 编码指令，确认目标后端包含 RoCC 发令路径。
- 两份 ELF 各对 40 项 Host 校验执行正确输出接受测试，以及错误输出、保护区损坏和错误 hart 的拒绝测试，均通过。
- Python 源码编译检查通过。
- Host 独立迁移打包/解压后的 ELF/数据绑定检查通过。

交付方用于离线验证的裸机 GCC 缺少默认 C 头搜索目录，构建时额外指定了本地 newlib 头路径；用户此前已成功编译 ResNet50 的 Chipyard 工具链通常无需该额外参数。
Host 验证依赖 pyelftools；fixture 生成依赖 NumPy。

未执行 RTL 仿真、Gemmini ISA 仿真或 VCU128 真板计算。这些离线检查不能代替板上 40 项逐元素验证。
若板上某项出现差异，应定位布局、驱动分支、缩放精度/位置或硬件行为，不修改预期数据来迁就错误输出。
